### Exercise 1 — IP Validator (Strings + Conditionals)

Write a program that takes a string input and checks:
- Is it null or empty? → print `"[-] No input"`
- Does it start with `"192.168."` → print `"[+] Private IP (Class C)"`

**Expected output (for 8.8.8.8):**

### Exercise 19 — DNS Covert Channel Encoder/Decoder (Strings + Loops + Methods)

Implement two methods that simulate DNS covert channel encoding:

**Encode:**
```csharp
string EncodeDNS(string command, string domain)
```
- Convert each char to its ASCII int value
- Join with `-`
- Append `.{domain}`
- Example: `EncodeDNS("whoami", "evil.com")` → `"119-104-111-97-109-105.evil.com"`

**Decode:**
```csharp
string DecodeDNS(string subdomain)
```
- Strip the domain part (everything after and including the first `.`)
- Split by `-`
- Convert each number back to a char
- Return the original command

Write a loop that encodes these commands and then immediately decodes them, verifying the round-trip:
```csharp
string[] commands = { "whoami", "hostname", "ipconfig", "cat /etc/passwd" };
```

Print `[OK]` if decoded matches original, `[FAIL]` otherwise.

### Exercise 20 — Mini Port Scanner Framework (Everything Combined)

Build a small, organized port scanning framework with the following methods:

```csharp

// 2. Simulate port check — randomly open/closed with weighted chance
bool CheckPort(string host, int port)

// 3. Grab fake banner based on port number
string GrabBanner(int port)

// 4. Scan one host across all given ports, return results
List<(int port, string banner)> ScanHost(string host, int[] ports)

// 5. Scan multiple hosts, aggregate all results
Dictionary<string, List<(int port, string banner)>> ScanNetwork(string[] hosts, int[] ports)

// 6. Generate final text report from scan results
string GenerateReport(Dictionary<string, List<(int port, string banner)>> results)
```

**Requirements:**
- `ValidateIP` uses `Split('.')` and checks 4 numeric octets in range 0–255
- `GrabBanner` returns realistic fake banners: `"OpenSSH_8.9p1"` for port 22, `"Apache/2.4.49"` for port 80, etc.
- `ScanNetwork` skips invalid IPs (using `ValidateIP`) and prints a warning
- `GenerateReport` uses `StringBuilder` and formats a full report with host sections, open ports, banners, and a grand total summary

**Test with:**
```csharp
string[] hosts = { "10.0.0.1", "10.0.0.2", "999.999.0.1", "10.0.0.3" };
int[]    ports = { 21, 22, 80, 443, 3306, 3389, 8080 };
```

```
[HOST] 10.0.0.1
```
