# C# — Steps 1–5: 20 Practical Exercises

**Topics covered:** Output/Input · Variables & Data Types · Type Conversion · Operators · String Operations

> Exercises progress from easy to hard. No topics outside Steps 1–5 are used.

---

## 🟢 Beginner (1–7)

### Exercise 1 — Colored Output
Use `Console.WriteLine` to print the following, each on a separate line, each in a different color:
- Your name
- Your age
- A `double` value (e.g. GPA: `3.87`)

Reset the color after each line using `Console.ResetColor()`.

---

### Exercise 2 — Name & Age Input
Read a name and an age from the user via `Console.ReadLine()`.
Convert the age to `int` using `int.Parse()`.
Print the result in this exact format:
```
[+] Hello, <name>! You are <age> years old.
```

---

### Exercise 3 — Type Tour
Declare one variable of each type below and print its value and type name using `.ToString()`:
```
byte · short · int · long · float · double · bool · char
```
Example output:
```
byte   → 255
short  → 32767
...
```

### Exercise 4 — Arithmetic Calculator
Read two integers from the user. Print:
- Sum, difference, product
- Integer division result
- Exact division result (use `(double)a / b`)
- Remainder (`%`)

Label each result clearly.

### Exercise 5 — IP String Operations
Given:
```csharp
string ip = "192.168.1.100";
```
Perform and print:
- Total length
- Uppercase version
- Split by `"."` — print each octet on its own line
- Extract the 3rd octet (`"1"`) using `Split` and index

### Exercise 6 — Nullable Port
Declare `int? port = null`.
Use the `??` operator to fall back to `80` if null.
Print:
```
[*] Port: 80 (default)
```
Then set `port = 443` and print:
```
[*] Port: 443
```

### Exercise 7 — Port Validator with Constants
Declare:
```csharp
const string VERSION = "1.0.2";
const int MAX_PORT = 65535;
```
Read a port from the user. Use `int.TryParse()` to parse it safely.
Check if it's in the range `1–65535`.
- Valid → print in green: `[+] Port 8080 is valid`
- Invalid → print in red: `[-] Invalid port number`

### Exercise 8 — Host:Port Parser
Read input in the format `"192.168.1.1:8080"` from the user.
Split on `':'`, separate host and port.
Parse port with `TryParse`. Validate the range.
Print host and port individually, or an error if invalid.

### Exercise 9 — Banner Parser
Parse this banner string:
```csharp
string banner = "OpenSSH_8.9p1 Ubuntu-3ubuntu0.6";
```
- Detect whether it contains `"SSH"` (case-insensitive)
- Extract the version string → `"8.9p1"`
- Extract the OS part → `"Ubuntu-3ubuntu0.6"`

Print each result on its own labeled line.

### Exercise 10 — CLI Argument Reader
Read `--target` and `--port` from `args[]` using a `for` loop.
Validate:
- `target` must not be empty
- `port` must parse and fall in range `1–65535`

On any error, print in red and `return`.
On success, print the parsed values in green.

### Exercise 11 — XOR Encrypt & Decrypt
Given:
```csharp
byte[] payload = { 0x90, 0x90, 0xC3 };
byte key = 0xAA;
```
XOR-encrypt the payload byte by byte.
Then XOR-decrypt the result using the same key.
Verify the decrypted output matches the original.
Print all three arrays (original, encrypted, decrypted) in hex format.

Read a `double` from the user (e.g. `3.99`).
Convert it two ways:
- `(int)` cast → truncates
- `Convert.ToInt32()` → rounds

Print both results with an explanation of the difference.

Convert the integer `255` to:

## 🔴 Advanced (15–20)

### Exercise 15 — DNS Covert Channel Encoder
Encode the string `"whoami"` into a DNS-style covert channel payload:
- Convert each character to its ASCII integer value
- Join with `"-"` → `"119-104-111-97-109-105"`
- Append `".evil.com"` to form a fake subdomain

Then decode it back:
- Split on `'-'`, parse each number, convert to `char`, join
- Verify the decoded result equals `"whoami"`

Print both the encoded subdomain and the decoded string.

---

### Exercise 16 — Sandbox Detection
Build a scoring-based sandbox detector. Award `+1` for each condition:
```
Environment.ProcessorCount < 2
Environment.TickCount64 < 3_600_000     (less than 1 hour uptime)
Environment.UserName is "sandbox", "user", or "admin"
Environment.MachineName.Length < 6
```
- Score `>= 2` → print in red: `[!] Sandbox detected (score: X)`
- Score `< 2` → print in green: `[+] Environment looks clean (score: X)`

---

### Exercise 17 — Verbose Flag Logger
Build a CLI tool that reads `--target`, `--port`, and `--verbose` from `args[]`.
Implement a `Log(string msg, bool onlyVerbose = false)` function:
- If `onlyVerbose` is `true`, only print when `--verbose` is set
- Otherwise always print

Validate port range. Print debug info (socket details, timing) only in verbose mode.
Print final result in color.

### Exercise 18 — Passwd Line Parser
Parse this line in `/etc/passwd` format:
```csharp
string line = "admin:password:1000:1000";
```
Split on `':'` with a limit of `4` fields.
Store each field in a named variable: `username`, `password`, `uid`, `gid`.
Parse `uid` and `gid` as `int`.
- If `uid == 0` → print in red: `[!] ROOT account detected`
- Otherwise → print all fields in a labeled table

### Exercise 19 — Port Scan Result Table
Use `StringBuilder` to build a formatted scan output table:
```
PORT       STATUS     SERVICE
80         OPEN       HTTP
443        OPEN       HTTPS
8080       CLOSED     HTTP-ALT
3306       OPEN       MySQL
```

Use string padding (`{value,-10}`) for alignment.

### Exercise 20 — Mini C2 Argument Parser
Build a full CLI argument parser that supports:
```
--target  <ip>       (required)
--port    <int>      (required, 1–65535)
--timeout <int>      (optional, default: 3000)
--verbose            (optional flag)
--version            (print version and exit)
```
Behavior:
- `--version` → print `[*] Scanner v1.0.0` and exit immediately
- Missing `--target` → print usage hint in red and exit
- Invalid `--port` → print error in red and exit
- Invalid `--timeout` (if provided) → print error in red and exit
- All valid → print full config in green:
```
[+] Target  : 192.168.1.1
[+] Port    : 8080
[+] Timeout : 3000ms
[+] Verbose : true
```
